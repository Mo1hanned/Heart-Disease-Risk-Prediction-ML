# 🫀 Clinical Heart Disease Risk Prediction using Machine Learning

## 📌 Project Overview
This project applies supervised Machine Learning (**Random Forest Classifier**) to clinical patient data to predict the likelihood of heart disease. It demonstrates how health informatics and data science can support early clinical decision-making.

## 📊 Clinical Features Analyzed
- **Age & Sex**
- **Chest Pain Type (`cp`)**
- **Resting Blood Pressure (`trestbps`)**
- **Serum Cholesterol (`chol`)**
- **Fasting Blood Sugar & Resting ECG**

## 🛠️ Technologies Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn

## 🎯 Key Results
- The Random Forest model achieved high diagnostic accuracy on unseen test patient records.
- Visualizations highlight strong correlations between age, chest pain types, and cardiovascular risk.
